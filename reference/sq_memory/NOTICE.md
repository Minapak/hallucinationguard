# swiftquantum_common.memory — attribution

Independent Python implementation. Ideas and data shapes come from:

- **Hindsight** — Copyright (c) 2025 Vectorize AI, Inc., MIT License.
  https://github.com/vectorize-io/hindsight — memory banks, the retain / recall /
  reflect operations, fact kinds (world / experience / observation), recall that
  fuses keyword, semantic, entity-graph and temporal arms with reciprocal rank
  fusion, bounded recency and proof-count boosts, and observations consolidated
  from supporting facts. No Hindsight code is included.
- **supermemory** — Copyright (c) 2025 supermemory, MIT License (published
  schemas). https://github.com/supermemoryai/supermemory — the memory version
  chain (version / isLatest / parent), relations updates / extends / derives,
  static vs dynamic profile with buckets, and time-based forgetting. The
  supermemory engine itself is not open source and was not used.
- **LLM Wiki pattern** — Andrej Karpathy, gist 442a6bf555914893e9891c11519de94f:
  sources → maintained interlinked pages, ingest / query / lint, index and log.
  No code, prompts or formats from GPL-licensed implementations (e.g.
  nashsu/llm_wiki) were used.
- Reciprocal rank fusion: Cormack, Clarke & Büttcher, SIGIR 2009. Okapi BM25:
  Robertson & Zaragoza, 2009.
